- `docs/figures/model_values_state.svg` — ModelStructure + ModelValues = Model; forward_kinematics_state(model, q) -> immutable KinematicState; dynamics.state reads it. Caption: "A Model holds static structure and differentiable values; each query produces its own immutable KinematicState." Page: concepts/model and kinematics.
- `docs/figures/joints_bodies_frames.svg` — world -> free-flyer J0 -> base -> J1 -> link1 -> J2 -> link2, frame `tool` on link2; parent/child, joint placement, frame placement. Caption: "Joints connect a parent body to a child body at a joint placement; frames are named poses fixed to a body." Page: concepts/model (joints, bodies, frames).
- `docs/figures/lie_spatial.svg` — world and body axes, translation t, pose layout [tx ty tz qx qy qz qw] (scalar last), twist [v, ω], LOCAL / WORLD / LOCAL_WORLD_ALIGNED. Caption: "Poses are [t, q] with a scalar-last quaternion; twists are [v, ω], expressed in one of three frames." Page: concepts/lie_and_spatial.
- `docs/figures/jacobians.svg` — frame twist = J (B, 6, nv) · v (B, nv); one column per DoF; three reference frames. Caption: "Column j of a frame Jacobian is the frame's twist when only DoF j moves at unit speed." Page: concepts/kinematics (Jacobians).
- `docs/figures/optim_problem.svg` — variables (B, *event) / time variables (B, T, *event), data, terms with reads, cached values -> Problem; loss(x) -> autograd solvers; linearize(x) -> normal equations (dense/banded/arrow) -> Solver init/step; Phase + run. Caption: "A Problem assembles plain-function terms over named variables; loss feeds autograd optimizers, linearize feeds the Gauss-Newton family." Page: concepts/optim.
- `docs/figures/banded_normal.svg` — block-tridiagonal normal matrix (T = 6, window = 2) with the arrow border for time-free variables β. Caption: "Time-local terms give a banded normal matrix; time-free variables add an arrow border; both solve in O(T)." Page: concepts/optim (time problems).
- `docs/figures/viewer_layers.svg` — Viewer (server, groups, timeline), robot_layers / RobotView -> layers fed (T, ...) arrays, tools (gizmo, picking), offline render. Caption: "The Viewer shows layers that each hold a whole clip; the same layers render offline without a server." Page: concepts/viewer.
