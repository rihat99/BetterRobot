# 0005 Configurations and velocities have different sizes

**Status:** Accepted · **Date:** 2026-10-07 (recorded; decision taken earlier)

## Context
A configuration `q` has `nq` entries and a velocity `v` has `nv`. They differ when a joint lives on a curved
space: a free-flyer root stores a position and a unit quaternion (7 numbers) but moves with a 6-D twist, so a
floating base has `nq = nv + 1`. Adding `v` to `q` with `+` pushes the quaternion off the unit sphere and mixes
units.

## Decision
We will keep `nq` and `nv` distinct everywhere and provide `Model.integrate(q, v)` and
`Model.difference(q0, q1)` as the only maps between them. Solvers step in the tangent space (`nv`) and map
back with `integrate`; residuals between configurations use `difference`.

## Consequences
`terms.RobotManifold(model)` exists; a phase's `free` mask has `nv` entries per knot. Code never assumes
`nq == nv`, even for fixed-base arms where it happens to hold.

## Alternatives considered
Store rotations as rotation vectors so `nq == nv` (singular at pi, slower composition); Euler angles (gimbal lock).

## Enforcement
C-TENS-3 (shapes name `nq`/`nv`); `tests/parity/` against Pinocchio; `[review]` for any `q + v`.
