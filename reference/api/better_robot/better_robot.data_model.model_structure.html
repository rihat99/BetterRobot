better_robot.data_model.model_structure#

Frozen topology shared by the torch and Warp compute lanes.

ModelStructure deliberately stores the robot topology twice: Python tuples keep the torch lane statically unrollable under torch.compile; flat tensors expose the same data to device kernels. Construction is the only place where the two representations are allowed to diverge, and validate_consistency makes that boundary explicit.
